01 / PROTOCOLS

协议不是限制，
输入框才是。

不用为每种链接换一个工具。粘贴链接或网盘分享页、选择文件、开始——剩下交给分段引擎。

HTTP / 01

HTTP / HTTPS

Range 分段并发，服务器不支持时自动回退单线程；暂停、续传、重试都在原地完成，不用重新开始。

  • Range
  • 断点续传
  • 单线程回退
  • 自动重试
FTP / 02

FTP / FTPS

账号密码可以直接写在链接里。单连接稳定下载，支持从 .part 继续，不重新拉整个文件。

  • 显式 TLS
  • 续传
  • 凭据隐藏
BT / 03

BitTorrent

打开 .torrent 或直接粘贴磁力链接。DHT + PEX 找 Peer，分片进度、Peer / 种子数量实时显示。

  • DHT
  • PEX
  • 分片
  • 多文件目录
MG / 04

Magnet

不需要先下载种子文件。磁力链接直接解析元数据，边找 Peer 边下载，断点信息保存在本地缓存。

  • 元数据
  • Peer
  • 种子
PAN / 05

网盘工作台

粘贴分享链接，在应用内登录百度、阿里、移动、天翼、迅雷、夸克、UC、123；按网盘页面选择文件，捕获官方直链后交给多线程引擎，并自动携带 Cookie、Referer 与 User-Agent。

  • 应用内登录
  • 直链捕获
  • Cookie
  • 手动 Cookie
  • 多线程

02 / FEATURES

快，但不粗糙。

线程数、进度、续传、队列、记录、更新——每个细节都为“下载完”服务。

CPU / THREADS

线程数，让 CPU 说了算。

根据逻辑核心与基础频率推荐并发数，默认上限 128；开发者模式可调到 512。不是越多越好，是刚好跑满。

128MAX THREADS
VISIBLE / PROGRESS

每一段，都看得见。

每个线程都有独立进度、速度和状态卡片，还有全局迷你线程图。卡在哪一段，一眼就知道。

实时速度 · 预计剩余 · 分段状态
RESUME

断了，就接着来。

.part 与 .part.json 保留中断状态，关闭程序、重启电脑后仍能继续。

QUEUE

一次粘贴，排队下完。

批量链接按顺序执行，支持停止、移出和失败重试，不用守着逐个开始。

HISTORY

下载过什么，找得到。

完成的文件自动记录，可打开文件、打开目录、重新下载或移除记录。

AUTO UPDATE / MULTI-THREAD

自动更新，也跑多线程。

更新包使用 HTTP Range 分段下载，最多 32 个线程并发；SHA-256 校验通过后才替换主程序并重启。旧版本第一次升级仍走旧逻辑，升到 2.2.1 后生效。

32 THREADS · SHA-256 VERIFIED
HOTKEY

一个快捷键，直接开工。

复制链接，按 Ctrl+Alt+D，自动填入并开始下载。组合键可在设置中重新录制。

全局下载限速

设置全局下载速度上限：不限速、1 / 5 / 10 / 20 MB/s 或自定义。HTTP 多线程任务由所有线程共享同一额度，合计不超过上限；FTP / BT 对之后开始的任务生效，自动更新不受限速影响。

  • 不限速 / 自定义
  • HTTP 多线程共享额度
  • FTP / BT
  • 自动更新豁免
